An offline Grand Theft Auto VI trophy guide and tracker for all 55 PlayStation trophies. It brings together original guide notes with cited reference guides, a three-step platinum roadmap, a clear warning for the single potentially missable trophy, and a progress tracker saved in your browser with JSON export and import. Turn on spoiler mode to mask unearned story trophies. No build step, external fonts, artwork, or runtime network requests are required.

## Run it

```sh
node serve.ts
# Open http://localhost:8080

mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```
